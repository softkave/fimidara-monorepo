# Image transformation
<br />

**fimidara** can resize and convert images **on the fly** when you read a file. Pass transform query parameters to `GET /v1/files/readFile/...` — you do not need to store multiple sizes upfront.
<br />

Transforms apply only when the file is a processable image. Animated GIF/WebP and multi-page TIFF are not fully supported yet; requesting `format=gif` encodes a still image.
<br />

## Authentication
<br />

You can call `readFile` with:

- An **`Authorization: Bearer <agent-token-jwt>`** header, or
- A **presigned path** in the URL (no auth header), which is ideal for `<img src="...">` and public links.

See also [Introduction](/docs/fimidara/introduction) for how agent tokens and the `Public` permission group work.
<br />

## Example
<br />

<code className="block break-all whitespace-pre-wrap rounded-md border bg-muted/40 p-2 text-xs font-mono">
  https://api.fimidara.com/v1/files/readFile/my-workspace/photos/hero.png?w=600&amp;h=400&amp;fit=cover&amp;pos=centre&amp;format=webp
</code>


<br />
<br />

With the JS SDK, build the same URL using:

<br />

```typescript
const url = getFimidaraReadFileURL({
  filepath: "my-workspace/photos/hero.png",
  width: 600,
  height: 400,
  fit: "cover",
  position: "centre",
  background: "#ffffff",
  withoutEnlargement: true,
  format: "webp"
});
```
<br />

## Presigned paths
<br />

Browser `<img>` tags cannot send an `Authorization` header. Issue a presigned path with `issuePresignedPath`, then use that id as the `filepath` in `getFimidaraReadFileURL` / `readFile`.
<br />

**Note:** `duration` on `issuePresignedPath` is in **milliseconds** (for example, `3_600_000` for one hour). Omit `duration` if the path should not expire.
<br />

## In-app playground
<br />

In the fimidara app, open an image file menu and choose **Image Transform** to preview query parameters and copy a request URL.
